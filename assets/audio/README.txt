ASSETS/AUDIO - Instrucciones
================================

Este directorio debe contener el archivo de audio MP3:
  - html5-semantico.mp3

El archivo debe ser:
  - Formato: MP3 (MPEG-1 Audio Layer 3)
  - Contenido: Narración en español sobre HTML5 Semántico
  - Duración aproximada: 2 minutos 30 segundos
  - Tamaño recomendado: ~2.4 MB
  - Codec: MP3 (compatible con todos los navegadores modernos)

CONTENIDO RECOMENDADO PARA GRABAR:
----------------------------------
"Bienvenidos a este breve tutorial sobre HTML5 Semántico. 
La semántica en HTML5 nos permite dar significado a nuestro contenido, 
mejorando la accesibilidad, el SEO y la comprensión del código. 
Elementos como header, nav, main, article, section, aside y footer 
ayudan a los navegadores y tecnologías asistivas a entender la estructura 
de nuestra página. Este es un concepto fundamental para desarrollar 
sitios web accesibles y bien estructurados."

HERRAMIENTAS PARA CREAR EL AUDIO:
--------------------------------
1. Audacity (gratis, multi-plataforma)
2. GarageBand (Mac)
3. Adobe Audition
4. Herramientas en línea como Vocaroo, Soundtrap

NOTA: El archivo actual es un marcador. Debes reemplazarlo con tu propia grabación.
