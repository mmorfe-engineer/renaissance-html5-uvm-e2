## 📚 Fuentes T\u00e9cnicas Consultadas

### Est\u00e1ndares Web

#### HTML5

1. **WHATWG HTML Living Standard**
   
   WHATWG. (s.f.). *HTML Living Standard*. Recuperado de https://html.spec.whatwg.org/multipage/
   
   > Est\u00e1ndar oficial de HTML mantenido por WHATWG. Fuente principal para la implementaci\u00f3n de elementos sem\u00e1nticos.

2. **W3C HTML5 Recommendation**
   
   World Wide Web Consortium. (2014). *HTML5: A vocabulary and associated APIs for HTML and XHTML*. W3C Recommendation. Recuperado de https://www.w3.org/TR/html52/
   
   > Recomendaci\u00f3n oficial del W3C para HTML5. Consulta para validaci\u00f3n de sintaxis y estructura.

3. **MDN Web Docs: HTML**
   
   Mozilla Developer Network. (s.f.). *HTML: HyperText Markup Language*. Recuperado de https://developer.mozilla.org/es/docs/Web/HTML
   
   > Documentaci\u00f3n completa y ejemplos pr\u00e1cticos para todos los elementos HTML.

#### CSS

4. **W3C CSS Specifications**
   
   World Wide Web Consortium. (s.f.). *CSS Specifications*. Recuperado de https://www.w3.org/Style/CSS/specs.es.html
   
   > Especificaciones oficiales de CSS del W3C.

5. **MDN Web Docs: CSS**
   
   Mozilla Developer Network. (s.f.). *CSS: Cascading Style Sheets*. Recuperado de https://developer.mozilla.org/es/docs/Web/CSS
   
   > Documentaci\u00f3n de referencia para propiedades CSS, selectores y hojas de estilo.

6. **CSS Tricks: A Complete Guide to Flexbox**
   
   CSS-Tricks. (s.f.). *A Complete Guide to Flexbox*. Recuperado de https://css-tricks.com/snippets/css/a-guide-to-flexbox/
   
   > Gu\u00eda completa sobre Flexbox, utilizada para layouts responsive.

7. **CSS Tricks: A Complete Guide to Grid**
   
   CSS-Tricks. (s.f.). *A Complete Guide to Grid*. Recuperado de https://css-tricks.com/snippets/css/complete-guide-grid/
   
   > Gu\u00eda completa sobre CSS Grid, utilizada para layouts complejos.

#### Accesibilidad

8. **W3C Web Accessibility Initiative (WAI)**
   
   World Wide Web Consortium. (s.f.). *Web Content Accessibility Guidelines (WCAG) 2.1*. Recuperado de https://www.w3.org/WAI/standards-guidelines/wcag/
   
   > Pautas de accesibilidad para contenido web. Referencia para contraste de colores, navegaci\u00f3n por teclado y estructura sem\u00e1ntica.

9. **MDN Web Docs: Accessibility**
   
   Mozilla Developer Network. (s.f.). *Accessibility*. Recuperado de https://developer.mozilla.org/es/docs/Web/Accessibility
   
   > Documentaci\u00f3n sobre accesibilidad en la web, atributos ARIA y buenas pr\u00e1cticas.

10. **WebAIM: Introduction to Web Accessibility**
    
    WebAIM. (s.f.). *Introduction to Web Accessibility*. Recuperado de https://webaim.org/intro/
    
    > Recursos educativos sobre accesibilidad web, utilizados para validar la implementaci\u00f3n.

#### Multimedia

11. **W3C HTML5: The audio element**
    
    World Wide Web Consortium. (s.f.). *HTML5: The audio element*. Recuperado de https://www.w3.org/TR/html52/semantics-embedded-content.html#the-audio-element
    
    > Especificaci\u00f3n oficial del elemento `<audio>` en HTML5.

12. **W3C HTML5: The video element**
    
    World Wide Web Consortium. (s.f.). *HTML5: The video element*. Recuperado de https://www.w3.org/TR/html52/semantics-embedded-content.html#the-video-element
    
    > Especificaci\u00f3n oficial del elemento `<video>` en HTML5.

13. **W3C WebVTT: The Web Video Text Tracks Format**
    
    World Wide Web Consortium. (2016). *WebVTT: The Web Video Text Tracks Format*. W3C Recommendation. Recuperado de https://www.w3.org/TR/webvtt1/
    
    > Especificaci\u00f3n oficial del formato WebVTT para subt\u00edtulos.

#### Validaci\u00f3n

14. **W3C Validator: Nu HTML Checker**
    
    World Wide Web Consortium. (s.f.). *Nu HTML Checker*. Recuperado de https://validator.w3.org/nu/
    
    > Herramienta oficial de validaci\u00f3n HTML5 utilizada para verificar la sintaxis.

15. **W3C CSS Validator**
    
    World Wide Web Consortium. (s.f.). *CSS Validator*. Recuperado de https://jigsaw.w3.org/css-validator/
    
    > Herramienta oficial de validaci\u00f3n CSS utilizada para verificar las hojas de estilo.

## 📋 Formato de las Referencias

Todas las referencias en este documento siguen el **estilo APA (7ma edici\u00f3n)** adaptado para recursos en l\u00ednea:

- **Autor o Organizaci\u00f3n:** Nombre del autor o la organizaci\u00f3n responsable
- **A\u00f1o:** A\u00f1o de publicaci\u00f3n (o "s.f." para sin fecha)
- **T\u00edtulo:** T\u00edtulo del recurso en cursiva
- **Edici\u00f3n:** N\u00famero de edici\u00f3n (si aplica)
- **Editorial:** Editorial o organizaci\u00f3n
- **URL:** Enlace directo al recurso
- **Nota:** Descripci\u00f3n breve del uso del recurso
